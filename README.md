# Factory Starter App

A Next.js application built with TypeScript, the App Router, Tailwind CSS, and ESLint.

## Requirements

- Node.js 20.9 or later
- npm

## Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application. The home page is defined in `src/app/page.tsx`.

## Available Scripts

- `npm run dev` starts the development server.
- `npm run build` creates a production build.
- `npm run start` serves the production build.
- `npm run lint` checks the project with ESLint.
